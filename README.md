# Context Knowledge Hub

This repository is the working knowledge base for Context.

It exists so AI tools and collaborators can quickly understand:
- what Context is,
- what the current offer is,
- how the webinar methodology works,
- what has been tested versus what is still a hypothesis,
- where the original source materials live.

## Start here

Read these files before making strategic recommendations about Context:

1. `context/OVERVIEW.md` — current high-level understanding of the business and offer
2. `context/SOURCES.md` — source index and what each source should be used for
3. `context/OPEN_QUESTIONS.md` — unresolved strategic questions and assumptions that should not be treated as settled

## Source-of-truth principle

Do not assume every statement in a source document is a finalized Context decision.

Source materials include:
- current working offer documents,
- webinar decks,
- webinar transcripts,
- research,
- operating models,
- historical thinking.

The overview and open-questions files exist to distinguish current working direction from evidence, examples, hypotheses, and older material.

## Current focus

Context is developing a managed webinar and acquisition system for B2B advisory firms. The strongest current differentiator is the post-webinar qualification, enrichment, prioritization, routing, and sales handoff layer, rather than webinar production alone.

The offer is still being refined. Treat pricing, ICP, scope, positioning, operating assumptions, and delivery model as working decisions unless explicitly marked as locked.
